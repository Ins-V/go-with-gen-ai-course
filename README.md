# Go With Gen AI Course

Homework and practice code for the "Go With Gen AI" course.

## Lesson 1

### Instruction for running the code

Run every program from the repository root.

#### Hello, world!

```bash
go run ./lesson-1/cmd/hello
# Hello, world!
```

#### Greet

```bash
go run ./lesson-1/cmd/greet Alice
# Hello, Alice! Welcome to Go.

go run ./lesson-1/cmd/greet
# Hello, stranger! Welcome to Go.
```

#### Converter

```bash
go run ./lesson-1/cmd/converter 100 41.5
# 100.00 = 4150.00
```

> **Notes** on writing `Greet` by hand versus with an AI assistant: [`lesson-1/greet/README.md`](lesson-1/greet/README.md).
